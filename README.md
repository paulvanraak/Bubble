# Bubble

This repository contains two independent projects:

- **[`mac/BubbleNotes`](mac/BubbleNotes)** — a native macOS sticky-notes app
  (SwiftUI + AppKit) where notes dock to the edge of your screen; hover to
  preview, click to pin, drag to reorder, archive/export when done. See
  [`mac/BubbleNotes/README.md`](mac/BubbleNotes/README.md) for build/run
  instructions.
- **Bubble Wrap Pop** (`index.html`, `styles.css`, `js/`) — a browser-based
  bubble-wrap popping idle-clicker game, deployed via GitHub Pages.
